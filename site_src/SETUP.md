# SatoshiShield site

A self-contained static site built from the project's existing markdown. No
Jekyll/Ruby — it uses a small Python generator, consistent with the rest of the
repo's tooling (`build_blocklists.py`, the monitor).

**The published site makes zero third-party requests.** Fonts (JetBrains Mono +
Newsreader) are self-hosted as local woff2; CSS is local; there is no analytics,
no CDN, no Google Fonts. A privacy tool's own site should not surveil its
visitors. (Open the network tab and confirm.)

## Layout

```
site_src/
  build_site.py            generator (reads docs/, writes site/)
  assets/
    style.css              the theme (editorial-cypherpunk, dark)
    fonts/*.woff2          self-hosted fonts (~124 KB total)
  templates/
    landing.html           the hand-built landing page
.github/workflows/pages.yml  builds + deploys to GitHub Pages on push to main
site/                       build output (generated — see .gitignore note)
```

## Build locally

```bash
pip install markdown
python3 site_src/build_site.py
```

Then preview (relative font/CSS paths need to be served, so open via a server,
not file://):

```bash
cd site && python3 -m http.server 8000
# visit http://localhost:8000
```

## Deploy (GitHub Pages, no local toolchain needed)

1. Repo **Settings > Pages > Build and deployment > Source: GitHub Actions**.
2. Push to `main`. The `pages.yml` workflow installs `markdown`, runs the
   generator, and deploys `site/`. Editing any doc in `docs/` and pushing
   rebuilds the site automatically.

## .gitignore

The `site/` directory is generated by CI, so it does not need to be committed:

```
/site/
```

(The prebuilt `site/` is included in this drop only so you can preview it
locally before wiring up Pages. Delete or gitignore it once CI is live.)

## What the generator does

- Renders every doc in the `DOCS` list (`build_site.py`) to a themed page.
- Generates a sidebar table of contents from each doc's H2/H3 headings, using a
  GitHub-matching slugify so the docs' own in-text TOC links resolve.
- Rewrites links: `*.md` -> `*.html`; other in-repo files (`domains.csv`,
  `blocklist.txt`, `LICENSE`, ...) -> their GitHub blob URLs; external links and
  anchors are left alone.
- Strips each doc's hand-written "Table of Contents" block (replaced by the
  sidebar).

To add or reorder documents, edit the `DOCS` list at the top of `build_site.py`.
To change fonts, drop new woff2 files in `site_src/assets/fonts/` and update the
`@font-face` blocks in `style.css`.
