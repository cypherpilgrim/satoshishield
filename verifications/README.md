# SatoshiShield — Verification Records

> **Public sanitized verification records.** Each file documents the research performed on a candidate domain before it was included in or excluded from the SatoshiShield blocklist. Internal lab infrastructure has been redacted. These are research artifacts, not legal or financial advice.

Every candidate runs through the same seven-step process: WHOIS/RDAP, SSL certificate inspection, passive DNS, behavioral evidence, privacy-harm assessment, inclusion-criteria scoring (six criteria), and a functional-impact test confirming no Bitcoin wallet breakage.

**20 records** — 15 verified for inclusion, 4 excluded, 1 consolidated into a parent vendor.
